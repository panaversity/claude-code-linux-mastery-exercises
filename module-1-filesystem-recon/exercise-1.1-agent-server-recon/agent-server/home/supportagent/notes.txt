Support Agent Notes
===================
Last updated: 2026-02-08 by jake@ops

Known quirks:
- The agent sometimes returns empty responses when the OpenAI API is slow.
  Workaround: We added a 5s retry in app.js (v1.4.2). Seems to fix it.

- Redis session store fills up if we don't clear expired sessions.
  The TTL is set to 30min in config.json but Redis doesn't always evict
  promptly. Manual flush every Sunday: redis-cli -n 1 FLUSHDB

- The /tmp/support-agent-cache/ directory grows unbounded.
  TODO: add a cleanup cron or systemd timer for this.
  For now I'm running: find /tmp/support-agent-cache -mtime +1 -delete
  manually every few days.

- Memory usage creeps up over time (suspected Node.js memory leak in
  the session Map). We restart the service weekly via:
  systemctl restart support-agent
  Should probably set MemoryMax in the service file.
  UPDATE 2026-02-01: Added MemoryMax=2G to service file. Monitoring.

- Knowledge base needs to be rebuilt when FAQ docs change.
  Process: ssh in, run: cd /opt/support-agent && node scripts/rebuild-kb.js
  Takes about 5 minutes. Service doesn't need restart.
